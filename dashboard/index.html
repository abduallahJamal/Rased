Worker-Pool Concurrency

Configurable pool with -c workers and -d inter-request delay. Graceful shutdown on SIGINT with Chromium cleanup.

-c 3 • -d 200 • -t 30000

Full Network Interception

Hooks every response event during rendering — XHR, fetch, scripts, stylesheets, fonts, images — with headers + timing + body.

page.on('response') • latency_ms

Mirrored Storage + .meta

Reconstructs URL tree to out/<host>/<path> and writes sidecar .meta JSON: headers, CSP, status, timestamp, latency.

out/<host> + .meta JSON

JS Execution Engine

Evaluate any JS in page context after load: -j "document.title", DOM scraping, telemetry, endpoint harvesting. Safe serialization.

-j "expr" → stdout

Scope & Filtering

--exclude / --include by MIME or substring, --no-third-party same-site only, --third-party external only.

--exclude image/ • --no-third-party

Proxy & TLS Control

Route through Burp/ZAP via -p http://127.0.0.1:8080 (HTTP/SOCKS5) with -k to ignore cert errors for interception.

-p proxy • -k insecure

Graceful shutdown — SIGINT / SIGTERM
def _install_signal_handlers(self):
    loop = asyncio.get_running_loop()
    for sig in (signal.SIGINT, signal.SIGTERM):
        loop.add_signal_handler(sig, self._shutdown.set)

async def stop(self):
    await self._browser.close()
    await self._playwright.stop()
    # Chromium processes reaped — no zombies
